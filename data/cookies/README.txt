Drop your yt-dlp cookie file(s) here (Netscape cookies.txt format, exported
from a logged-in YouTube session in your browser - e.g. via the "Get
cookies.txt LOCALLY" extension).

Supported filenames, tried in order until one works:
  cookie.txt
  cookie1.txt
  cookie2.txt
  cookie3.txt
  cookie4.txt

This is especially important when running on a VPS - YouTube frequently
rate-limits or outright blocks anonymous requests from cloud/datacenter IP
ranges, and a valid cookie file is usually the fix. If the first cookie
file fails or expires, the bot automatically tries the next one.

These files are never uploaded anywhere by the bot and are excluded from
the "Download data backup" button in the dashboard.
